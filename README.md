## A student portal project for practicing Git and GitHub collaboration, version control workflows, and component structuring.

## Project Overview
This repository contains the foundational components for the Student Mobile Portal, featuring a modular profile display component built with React/JSX.

## Components
StudentProfile.jsx: A reusable profile component that displays student details including name, student ID, and academic program.

## Git & GitHub Workflow
Developed using isolated feature branches.
Tracked via structured, meaningful commits.
Integrated into the main branch through Pull Requests and code reviews.
